# 旅游列车跨部门开行

协调旅游列车的铁路运行资源、地方接待与旅客变更。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括铁路客运部门、地方文旅部门、旅游服务商、团体旅客。

资料所依据的领域事实如下：

- 铁路部门主动对接各地文旅部门设计旅游列车线路
- 前八个月累计开行二千五百零一列旅游列车
- 旅游列车分为旅游专列与旅游专线列车

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
